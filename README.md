# AutoCorrector
Данная программа представляет собой приложение для исправления орфографических, пунктуационных и грамматических ошибок в текстах с помощью LLM. Приложение работает с текстом, который пользователь вводит непосредственно в форме. Также пользователь имеет возможность вставить исходный текст и отправить его на проверку.
